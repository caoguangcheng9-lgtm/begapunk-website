# 产品事实建议处理顺序

1. **先确认型号身份。** 优先处理BP-2P-30-0001/BP-3P-30-0001和BP-2P-95-0001/BP-2P-95-0005的身份冲突。
2. **再确认对应PDF和图纸。** 为每个型号指定当前受控文件、文控号、修订号、日期和适用配置；文件名不能代替内部标题栏核验。
3. **再确认压力、转速和温度。** 明确最大/连续/间歇值及介质、温度、密封和占空比条件。
4. **再确认重量和材料。** 统一净重口径、装配范围、材料BOM、表面处理和证书覆盖范围。
5. **最后确认测试压力及测试方法。** 明确测试介质、压力、保压时间、样本范围、合格标准和型号例外；BP-2P-95测试压力在依赖项解决前不裁决。
6. **确认后才修改公开资料。** 经Begapunk书面确认且明确允许后，才同步修改网页可见内容、JSON-LD、产品目录/对比页、PDF文件名或下载链接，并再次做跨页面一致性检查。

不得先修改网站再补证据；也不得用网页重复、文件更新时间或型号命名规律替代工程确认。
