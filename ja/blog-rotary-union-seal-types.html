ロータリージョイントのシール方式を比較

📅 2026年6月6日 所要時間:7分 🔧 シール技術 Begapunkエンジニアリング
シェア： LinkedIn X Facebook WhatsApp

同じ外形のロータリーユニオンでも、シール設計が違えば摩擦、発熱、摩耗、漏れ、圧力安定性が変わります。対象型式の許容範囲内で使い、実機条件に合わせて選定してください。

Begapunkのロータリージョイントでは、主にFKM Oリング、PTFE系リップシール、ばね入りカーボン充填PTFEを用途に応じて検討します。本ガイドでは構造、圧力、動作、流体、漏れ、保守性の違いを説明します。

要点：万能なシールはありません。圧力、動作、流体、温度、漏れ許容値を満たす構造を、余裕を含めて選びます。

1. Oリングシール

構造と作動原理

Oリングは、加工溝に組み込む環状のエラストマーシールです。組立時にハウジング内径と回転軸の間で圧縮され、溝側の静的シールと軸表面の動的シールを形成します。

Oリングの密封力は主に弾性圧縮で生じます。構造は簡潔ですが、経時硬化、圧縮永久ひずみ、摩耗により密封力が低下するため、材質とデューティを確認します。

圧力と動作の許容範囲

Oリングは圧縮と接触で密封する動的シールです。高圧では隙間へのはみ出し、高速では摩擦熱、硬化、摩耗が課題になります。限界値を一律に決めず、隙間、材質、径、潤滑、温度、圧力、動作で評価します。

Begapunk仕様の確認：

  • BP-1P-0003（1流路、ねじ取付）：FKM Oリング仕様。圧力、回転数、連続運転条件は最新データシートで確認
  • BP-2P-0001（2流路、フランジ取付）：FKM Oリングとバックアップリング仕様。許容条件は最新データシートで確認

流体適合性

素材: 使用可能流体 適合しない可能性がある流体
**FKM（フッ素ゴム）** 乾燥空気、鉱物油、作動油、溶剤。具体的な銘柄と温度で適合性を確認 蒸気、温水、極性溶剤、アンモニア。温度と材質適合性を個別確認
**NBR（ニトリルゴム）** 水、クーラント、一般油。具体的な銘柄で適合性を確認 オゾン、高温空気、芳香族炭化水素。材質グレードを個別確認
**EPDM** 温水、蒸気、極性溶剤。温度と材質適合性を個別確認 鉱物油、作動油、グリース。添加剤と温度を確認

重要：湿気を含む圧縮空気では、FKMの劣化速度は露点、温度、潤滑、圧力、運転時間で変わります。固定期間で寿命を断定せず、空気品質と材質適合性を確認してください。

Oリングが適する条件

  • 低圧の空圧クランプ。実圧力波形を確認
  • 間欠回転。平均値だけでなくピーク速度と停止時間を確認
  • 乾燥・ろ過された圧縮空気
  • 交換作業を許容でき、コストを重視する用途
  • 省スペースが必要な1流路ジョイント

Oリングを避けるべき条件

  • 連続使用圧力が高い用途。型式別の許容条件を確認
  • 長時間の回転用途。固定回転数ではなく型式別の許容条件を確認
  • 湿気またはオイルミストを含む空気で、保守頻度を抑えたい用途
  • 漏れ量を厳しく管理する用途。ゼロと断定せず検証値で判定

2. リップシール

構造と作動原理

リップシールは、金属ケースに保持されたエラストマーまたはPTFEのリップで構成されます。構造によってはガータースプリングが接触荷重を補います。リップ角度や潤滑作用は設計ごとに異なるため、固定角度を一律に適用しません。

リップシールは軸表面に接触する動的シールです。構造によってはガータースプリングが摩耗に伴う接触荷重の低下を補い、金属ケースが剛性とハウジングへの保持力を与えます。

Begapunkのリップシールでは、用途に応じて次の構造を検討します。

  • PTFEリップ＋ステンレスケース — 耐薬品性と低摩擦が必要な用途の候補
  • FKMリップ＋炭素鋼ケース — 一般産業用途の候補。流体と腐食条件を確認

圧力と動作の許容範囲

ばね荷重、リップ形状、圧力、径、隙間を組み合わせて設計します。固定のばね荷重や圧力上限を全型式に適用せず、対象構造で検証します。

許容動作はリップ部の温度、径、面粗さ、流体、圧力、潤滑で決まります。PTFEはFKMより低摩擦となる場合がありますが、固定の摩擦係数や温度を全型式へ適用できません。

Begapunk仕様の確認：

  • BP-2P-130-0001（2流路、高負荷仕様）：PTFE系リップシールとFKM Oリング仕様。圧力、回転数、流体を個別確認
  • BP-2P-50-0001（2流路、防塵仕様）：PTFE系リップシール。防塵性能と許容条件は最新仕様書で確認

流体適合性

PTFEは広い薬品耐性を持ちますが、充填材、温度、圧力、相手材、透過性によって制約があります。使用前に具体的な流体で確認してください。

  • 水、水溶性クーラント。組成、濃度、温度を確認
  • 作動油（ISO VG 32、46、68など）。添加剤と温度を確認
  • 弱酸・弱アルカリ。濃度、温度、材質を確認
  • 食品接触用途の水。必要な適合資料を持つ材質だけを採用

PTFE系シールの制約は化学適合性だけではありません。荷重下のクリープ、摩耗、温度、相手面の状態で隙間と漏れが変わります。交換時期は年数ではなく状態監視と検証結果で決めます。

リップシールが適する条件

  • 中圧の空圧・油圧用途。型式別の許容条件を確認
  • 連続回転用途。実回転数、シール径、温度上昇を確認
  • Oリングで早期劣化が起きる湿潤・油分環境
  • 長いシール寿命が必要な用途。期間ではなくデューティと検証結果で評価
  • 各流路のシール交換が難しい多流路ジョイント

リップシールを避けるべき条件

  • 高圧用途。標準仕様の範囲を超える場合は専用設計と検証が必要
  • 高速連続運転。型式別の許容条件と温度上昇を確認
  • 目視漏れを厳しく管理する用途。許容漏れ量と試験方法を合意
  • リップや相手面を傷つける研磨粒子が多い環境

3. ばね入りカーボン充填PTFEシール

構造と作動原理

ばね入りシールは、PTFE系シール材と付勢ばねを組み合わせた構造です。主な構成は次のとおりです。

  1. カーボン充填PTFEシールリング — 摺動面を構成
  2. ステンレス製カンチレバーばね — 接触荷重を付与
  3. バックアップOリングまたは付勢部材 — 高圧時のはみ出し抑制を補助

このばねはガータースプリングではなく、PTFE系シールを付勢するカンチレバーばねです。PTFEの充填材と配合率は摩耗、熱伝導、流体適合性に影響するため、承認材質で確認します。

適切に設計されたばね入りシールは、摩耗に伴う接触荷重の変化を補い、漏れと摩擦の安定化に役立ちます。寿命全体の一定性能を無条件には保証しません。

圧力と動作の許容範囲

カンチレバーばねは、PTFE系シール材の摩耗に追従して接触荷重を補う部品です。設計時に確認する項目は次のとおりです。

  • ばね荷重を用いる高圧仕様：連続使用圧力は型式別に確認
  • BP-2P-95-0001の高圧仕様：連続使用条件は最新図面・仕様書で確認
  • PTFE摺動面を用いる高速仕様：許容回転数は型式別に確認

高圧・回転条件でのシール温度は、径、面粗さ、潤滑、流体、圧力、速度によって変わります。PTFEとFKMの温度を固定値で比較せず、対象型式で温度上昇と寿命を検証します。

Begapunk仕様の確認：

  • BP-2P-95-0001（2入力4出力、高圧仕様）：ばね入りPTFE系シール。使用圧力、回転数、試験条件は承認仕様で確認

ばね入りPTFEは低漏れ化に有利な場合がありますが、改善倍率や漏れ等級は型式と試験条件で確認します。真空保持や精密空圧では、許容漏れ量を数値で合意してください。

ばね入りPTFEが適する条件

  • 高圧の油圧・空圧用途。対象型式と安全要求を個別確認
  • 高速連続回転。型式別の許容回転数と温度上昇を確認
  • 低摩擦トルクが必要な用途（ロボット、インデックステーブルなど）
  • 真空、クリーンルーム、精密クランプなど低漏れが必要な用途。許容漏れ量を数値で定義
  • 長い保守間隔が必要な用途。固定年数ではなく検証結果で判断

ばね入りPTFEを避けるべき条件

  • コストを重視する低圧空気用途
  • 研磨粒子が多い用途。充填材を含む摺動材でも相手材の摩耗を確認
  • 極低速・微小揺動では潤滑膜と接触状態を確認
  • 軸表面が対象シールの要求粗さを満たさない場合。固定値ではなく承認図面で確認

適切なシール方式の選び方

次の判断手順を参考にしてください。

手順1：使用圧力を確認

  • 低圧域 → Oリングまたはリップシールを条件に応じて選定
  • 中高圧域 → リップシールまたはばね入りPTFEを条件に応じて検討
  • 高圧域 → 型式別にシール構造と許容圧力を確認

手順2：実際の回転・揺動条件を確認

  • 低速域 → すべてのシールが使えるとは限らないため条件確認
  • 中速域 → リップシールまたはばね入りPTFEを条件に応じて検討
  • 高速域 → 型式別にシール構造、径、温度上昇を確認

手順3：許容漏れ量を確認

  • 目視可能な液滴を許容できる用途 → Oリングを候補として評価
  • 微量のにじみを許容できる用途 → リップシールを候補として評価
  • 厳しい目視漏れ管理 → ばね入りPTFEを候補とし、試験で確認

手順4：使用流体を確認

  • 乾燥空気 → FKM OリングまたはPTFE系リップシールを条件に応じて選定
  • 水・クーラント → 適合確認済みのPTFE系リップシールまたはばね入りPTFEを検討
  • 油・作動油 → 流体適合性を確認したFKM/PTFE系リップシールまたはばね入りPTFEを検討
  • 薬液・蒸気 → 温度と薬品適合性を確認したPTFE系ばね入りシールを検討

手順5：保守・点検条件を確認

  • 定期交換を許容できる用途 → Oリングを候補として評価
  • 固定年数ではなく、漏れ、摩耗、摩擦、点検結果からリップシールを評価
  • 保守間隔が長い、またはアクセスしにくい場合 → ばね入りPTFEを候補として評価

まとめ

シール選定はブランドの好みではなく、圧力、動作、流体、漏れ許容値、保守性に基づく設計判断です。

  • Oリングは、低圧・低速の乾燥空気用途で、簡潔さとコストを重視する場合の候補です。
  • リップシールは中圧・中速域や湿潤・油分を含む環境の候補です。交換時期は運転条件と点検結果で決めます。
  • ばね入りPTFEは、高圧、高速、厳しい漏れ管理、保守アクセスの制約がある用途の候補です。採用前に型式別の適合確認が必要です。

Begapunkでは、各型式の使用範囲に合わせてシール候補を設定します。材質名や圧力だけで自動選定せず、実際の用途条件と承認仕様を照合します。

ロータリージョイントのシール選定でお困りですか？ 圧力、動作、流体、温度、漏れ許容値、保守条件をお知らせください。適合するシール構造と材質を確認して提案します。
