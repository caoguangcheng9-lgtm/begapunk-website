ロータリージョイントの漏れを順番に診断する方法

日 時 5月 24, , 2026 所要時間 6分 ☑ 中級 Begapunkエンジニアリング
シェア： LinkedIn X Facebook WhatsApp

対象：産業用自動化設備で空圧ロータリージョイントの漏れを調査する保全技術者、信頼性技術者、設備管理者向けです。

⚡ 重要ポイント

  • 漏れは症状であり、必ずしも根本原因ではありません。圧力、動作、空気品質、取付を順に確認します。
  • 実際の運転サイクル中にジョイント入口圧力を測定し、対象型式の連続・ピーク許容圧力と比較
  • 具体的なデータシートで動作パターンとシール仕様を照合し、FKM、PTFE、複合材に一律の回転数上限を設定しない
  • 空気品質を確認：水分・粒子はシールリップと軸表面を損傷する場合があります
  • 不要な部品交換を避けるため、分解前に6ステップ診断フローを実施

漏れには事前の兆候がある場合があります。圧力、動作、空気品質、配管、取付を確認せずにシールだけを交換すると、同じ不具合が再発する可能性があります。

本ガイドは空圧ロータリージョイントの体系的な診断手順です。標準・多流路型式の参考として使用し、許容圧力と保全方法は必ず対象BP型式の最新データシートで確認してください。高圧型式の BP-2P-130、BP-2P-95 も個別確認が必要です。

漏れ位置から原因を絞り込む

回転摺動部からの漏れ

回転摺動部では多くのシール不具合が目視できます。固定ハウジングと回転軸の間から空気が漏れる場合、次の3項目を順に確認してください：

1. 使用圧力と許容圧力

連続圧力とピーク圧力を対象型式の承認範囲内に保ちます。高負荷で連続運転する場合は温度、タクト、圧力変動、保全周期も併せて評価してください。

シールを原因と判断する前に、レギュレータ設定、測定位置、動的な圧力変動を確認します。注記：ISO 4414:2010 は空圧システム圧力の安全な設計・管理を求めますが、シール寿命のための一律の定格比率は規定していません。

2. 回転・揺動条件とシール仕様

シール材と構造は、実際の動作、圧力、温度、媒体に適合させます：

シール材 回転・動作範囲 代表的な用途
FKM（フッ素ゴム） < 200 min⁻¹> 一般自動化・インデックステーブル
PTFE 中～高回転域：型式ごとに確認 包装設備の連続・高頻度回転
特殊複合材 高回転域：具体的なシール仕様の承認が必要 高速スピンドル：技術承認されたカスタム仕様のみ

用途に合わないシール材は、高速時の摩擦熱、媒体、変形によって早期摩耗する場合があります。FKMやPTFEという材質名だけで回転上限は決まりません。具体的な型式のシール形状、潤滑、圧力、温度、動作パターンを確認してください。

BP-2P-0001 のシール仕様と許容動作は、注文前に最新データシートまたは見積仕様で確認してください。高回転または連続運転には明示的に承認された構成を選びます。

3. 圧縮空気品質（水分・粒子）

水分、さび、配管摩耗粉、コンプレッサ由来の残留物は、シールリップや軸表面を損傷する場合があります。影響はシール材、濃度、温度、保全状態によって異なります。

フィルタ、レギュレータ、必要に応じてルブリケータで構成されるFRLを確認：

  • フィルタエレメント：メーカー指定の差圧上限または記録した保全周期で交換
  • 水分離器：メーカーの保全計画に従って排水。目視できる凝縮水があれば、空気処理と配管状態を確認
  • ルブリケータなし：乾式運転用として承認されたシールなら正しい場合があります。潤滑の可否・必要性はシール配合、媒体、メーカー承認で決まり、一律の寿命延長は保証できません。

ねじ接続部からの漏れ

NPTまたはGねじ部の漏れでは、まずねじ、シール方式、施工を確認します。本体が原因とは限りません。

確認1：ねじシール材の施工

PTFEテープは巻き方向、材質、巻き量が不適切だと漏れやめねじへの過大応力を招きます。一律の巻き数ではなく、ねじ規格、継手、テープ厚、メーカー要領に従い、流路側へテープ片を出さないでください。

確認2：締付過多による損傷

アルミねじは、工具の掛け方、シール方法、斜め締め、過大な締付で損傷する場合があります。指定の二面幅で本体を保持し、図面または取付要領の方法・トルクで接続してください。一律の締付トルクは使用しません。

照明を使って入口側ねじ山とポート周辺を確認します。亀裂が見える場合は圧力を抜いて停止し、交換してください。シール材では構造亀裂を修理できません。許容トルクと施工方法は図面またはメーカー資料に従います。

ベント／ドレン開口からの漏れ

一部のロータリージョイントにはベント／ドレン開口があります。少量の排気が正常かどうかは、具体的な構造と運転状態についてメーカー確認が必要です。急に増えた場合は設備を安全停止して原因を調査してください。

ベント開口から、構造と運転状態で許容される量を超える空気が出る場合：

  • 内部軸シールの摩耗、損傷、誤組付け
  • 流路間の差圧により、損傷・不適合な内部隔壁シールを越えてクロスリークが発生

対象型式で内部シールの現場修理が認められていない場合は、本体を交換するか認定サービスへ点検を依頼します。

クイック診断フロー

分解前に次の順序で確認：

ステップ1：漏れ位置を特定

→ 回転摺動部：ステップ2へ

→ ねじポート：ステップ5へ

→ ベント／ドレン：設備を安全停止し、取扱説明書に従って構造を確認後、ステップ6へ

ステップ2：システム圧力を確認

連続圧力またはピーク圧力が型式承認外ですか？

✓ はい → 承認範囲まで圧力を下げて再確認

✗ いいえ → 圧力は承認範囲内。ステップ3へ

ステップ3：動作条件とシール仕様を照合

使用中のFKM仕様に対して動作条件が承認範囲外ですか？

✓ はい → 実動作に合うシール仕様へ変更、または運転条件を調整

✗ いいえ → 動作とシール仕様は適合。ステップ4へ

ステップ4：空気品質とFRLを確認

過剰な水分または粒子がありますか？

✓ はい → FRLを整備して再確認

✗ いいえ → 条件は承認範囲内。ステップ6へ

ステップ5：ねじ接続を確認

ねじシール材と締付方法は正しいですか？

✓ はい → 正しく再施工して再確認

✗ いいえ → ハウジングねじに亀裂・損傷。本体を停止して交換

ステップ6：診断結果を記録

圧力、動作、空気品質、漏れ位置、交換部品番号を記録します。同じ設備で再発する場合は、設計、保全、調達へ情報を戻してください。

修理と交換の判断

ロータリージョイント本体を交換する条件：

  • ハウジングねじに亀裂またはねじ山損傷がある
  • ハウジングに衝撃痕または変形がある
  • 内部隔壁シールの損傷、または差圧への不適合
  • 軸受すきままたは軸振れが型式固有の摩耗限界を超える

シールキットのみを交換できる条件：

  • 漏れ位置は回転摺動部
  • ハウジングと軸に機械的損傷がない
  • 圧力、動作、空気品質が承認範囲内

BPシリーズのシールキット内容は型式によって異なります。構成部品、組付け方向、現場交換の可否を、対象シリアルの部品表と取付要領で確認してください。

有効な予防策

以下は一般的な保全事例を整理した診断手順で、型式ごとの確認に代わるものではありません。

  1. ロータリージョイント入口で圧力を測定します。コンプレッサや離れたFRLの表示では、配管・バルブ損失を正確に把握できません。実際の運転サイクル中に測定し、レギュレータ設定と測定位置を記録してください。
  2. 実生産時の回転数と動作パターンを記録します。無負荷運転では負荷、加減速、実タクトを再現できない場合があります。
  3. シール交換は状態とリスクに基づいて計画します。漏れ、回転抵抗、圧力、温度、サイクルの傾向を使い、推定寿命に一律の割合を掛けた交換基準は使用しません。
  4. 適合する予備シールキットを識別表示して設備近くに保管します。保全前に部品番号、保管状態、対象型式を確認し、誤部品の組付けを防ぎます。

まとめ

ロータリージョイントの漏れは、圧力、動作、空気品質、取付、摩耗のいずれかが想定範囲から外れた兆候である場合があります。シールや本体を交換する前に6ステップの診断を行い、結果を記録してください。

シールキットまたは交換用ジョイントが必要ですか？

診断結果がシール摩耗を示す場合、現場交換が認められたBP型式については 取付ガイド を参照してください。高圧、高速、腐食性環境では完全な使用条件をお送りください。
