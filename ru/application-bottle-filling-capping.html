Планирование применения

Ротационные соединения для машин розлива и укупорки

Разрешённый заказчиком производственный снимок показывает BP-2P-16-0001 с двумя независимыми воздушными проходами к трёхкулачковому захвату крышки.

Два прохода сжатого воздуха зажимают и разжимают захват при вращении укупорочной головки. Опубликованные данные — на странице модели: воздух, PTFE + O-кольцо, 1 МПа, 200 об/мин.

Применение на оборудовании заказчика

BP-2P-16-0001 в укупорочной головке

На опубликованной с разрешения заказчика фотографии показано ротационное соединение BP-2P-16-0001, установленное на его производственной машине. По двум независимым проходам подаётся сжатый воздух для зажима и разжима трёхкулачкового пневматического захвата. Захват удерживает крышку и вращает её при укупорке.

Ещё один вариант для этого применения

BP-2P-08-0001 — ещё один вариант для трёхкулачкового пневматического захвата. В показанной установке используется BP-2P-16-0001. Перед рекомендацией мы сравним число проходов, монтажный интерфейс, давление, частоту вращения и размеры.

Проверить соединение для сходной укупорочной головки
