Подача сжатого воздуха во вращающийся задний патрон

Для кого: для производителей станков лазерной резки труб и инженеров, проектирующих пневматическую систему заднего патрона.

Ротационное соединение передаёт независимые контуры сжатого воздуха через границу между неподвижной подачей и вращающимся задним патроном. Число контуров и режим работы определяются по чертежу патрона и пневматической схеме.

BP-3P-0004 и BP-2P-08-0001 — стандартные модели для независимых контуров сжатого воздуха заднего патрона в этой категории применения. Цеховые фотографии документируют категорию применения; показанные изделия не сопоставлены по отдельности ни с одной из этих моделей.

Исходные данные для подбора

  • Количество независимо управляемых пневматических контуров
  • Рабочее давление каждого контура сжатого воздуха
  • Максимальная и непрерывная частота вращения
  • Доступное пространство и геометрия заднего патрона
  • Присоединительные размеры и монтажная схема
  • Направление шлангов и пространство для обслуживания
Подтверждённые модели

Стандартные модели для сжатого воздуха заднего патрона

BP-3P-0004 и BP-2P-08-0001 применяются в контурах сжатого воздуха заднего патрона. Окончательное исполнение выбирается по чертежу станка и письменной инженерной проверке.

BP-3P-0004Три независимых канала для контуров сжатого воздуха. Для конкретного патрона подтверждаются назначение каналов, рабочее давление, частота вращения, монтажные размеры и направление шлангов.BP-2P-08-0001Два независимых канала для контуров сжатого воздуха. Для конкретного патрона подтверждаются назначение каналов, рабочее давление, частота вращения, монтажные размеры и направление шлангов.
Инженерная проверка

Контрольный список для заднего патрона

1. Определить пневматические контуры

Учитывайте только контуры сжатого воздуха, требующие независимого управления. Окончательное назначение каналов фиксируется по пневматической схеме станка.

2. Задать режим работы

Укажите рабочее давление, максимальную и непрерывную частоту вращения. Выбранная модель проверяется по утверждённым данным изделия для фактического рабочего цикла.

3. Проверить интеграцию

До подтверждения исполнения совместно проверяются чертёж патрона, присоединительные размеры и доступное пространство, монтажная схема, направление шлангов и доступ для обслуживания.

Вопросы о пневматической подаче в задний патрон

Какие стандартные модели применяются для сжатого воздуха заднего патрона?

BP-3P-0004 и BP-2P-08-0001 применяются в независимых контурах сжатого воздуха заднего патрона. Число каналов и присоединения выбираются по конструкции станка.

Как выбрать модель для заднего патрона?

По чертежу патрона необходимо подтвердить число независимых пневматических контуров, рабочее давление, максимальную и непрерывную частоту вращения, доступное пространство, присоединительные размеры и направление шлангов.

Как реализуется передача технологических или вспомогательных газов?

Для технологических или вспомогательных газов разрабатывается отдельное инженерное решение с материалами, очисткой, испытаниями и согласованием под конкретное применение.
